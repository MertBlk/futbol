# Futbol TypeScript Projesi

Bu proje, temel bir TypeScript başlangıç şablonudur.

## Komutlar

- Projeyi derlemek için:
  ```sh
  npm run build
  ```
- Projeyi başlatmak için:
  ```sh
  npm start
  ```

## Gereksinimler
- Node.js
- npm

## Klasör Yapısı
- `src/` — TypeScript kaynak dosyaları
- `dist/` — Derlenmiş JavaScript dosyaları

---

Başlangıç için `src/index.ts` dosyasını düzenleyebilirsiniz.
